# 忘年会 景品ファインダー

予算とジャンルを選び、Amazon.co.jpの検索結果を別タブで開くシングルページのWebアプリです。ダークテーマ、5つの価格帯、9つのジャンル、URLによる選択状態の共有に対応します。バックエンド・認証・商品情報取得・アクセス解析はありません。

React / TypeScript / Vite / Tailwind CSS / Lucide React / Vitestを使用しています。

## ローカル開発

Node.js 22系とnpmを使用します（CIもNode.js 22）。

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

## 検証・ビルド

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

ビルド結果は `dist/` です。`base: './'` により `/gift-finder/` などのリポジトリ名を含むサブパスとドメイン直下のどちらでもアセットを解決できます。クライアント側のルーティングは使用しません。

## GitHub Pagesの設定・デプロイ

1. GitHubのリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更してください。
2. `main` ブランチにpushすると `.github/workflows/deploy.yml` が実行されます。
3. `npm ci` → 型チェック → Vitest → ビルドが成功すると、GitHub公式のPages Actionsが `dist/` をデプロイします。
4. **Actions → Deploy GitHub Pages → Run workflow** から手動実行もできます。

公開予定URL: https://sato4432.github.io/gift-finder/

GitHubのプランやリポジトリの公開設定によってPagesの利用条件が異なります。組織等でActionsの利用制限がある場合は公式Actionsの利用を許可してください。

## 使い方・共有

予算とジャンルはそれぞれ1つ選択します。初期値は「1,001〜5,000円」「家電」です。選択は再読み込みなしでURLへ反映されます。

```text
?budget=1001-5000&category=electronics
```

URLをコピーして共有すると同じ条件で開けます。不正な値は各項目のデフォルトに戻ります。予算とジャンルには標準のラジオボタンを用い、Tab・矢印キー・Spaceで操作できます。

## Amazon検索URLの仕様・検証状況

価格帯とジャンルは `src/finder.ts` の定数に集約しています。独立した `buildAmazonUrl` 関数が `URL` / `URLSearchParams` を用い、日本語キーワードと円単位の価格をエンコードします。

```text
https://www.amazon.co.jp/s?k=家電&low-price=1001&high-price=5000
```

外部リンクは `target="_blank" rel="noopener noreferrer"` を指定しています。アフィリエイトタグは付与しません。

### 2026年11月13日時点の検証

この環境のWeb取得ツールではAmazonにアクセスできませんでしたが、ローカルのChrome（未ログイン）では検索結果を開けました。商品情報のスクレイピングやアプリへの取り込みはしていません。

- 家電検索で5つすべての予算を開き、HTTP 200と、Amazon画面上の価格フィルター表示が指定範囲に一致することを確認しました。
- `low-price` / `high-price` が、そのまま維持される場合と `rh=p_36:...` へ変換される場合を確認しました。変換された値は円の100倍でした。`rh=p_36:100100-500000` を直接開いた場合も検索結果を表示できました。
- 実装では、5予算で画面上の適用を確認できた、円単位の `low-price` / `high-price` を使用します。

| 予算 | Amazonの価格表示 | 観測した `p_36` への変換値 |
| --- | --- | --- |
| 1,001〜5,000円 | ￥1,001 ～ ￥5,000 | 100100-500000 |
| 5,001〜10,000円 | ￥5,001 ～ ￥10,000 | 500100-1000000 |
| 10,001〜30,000円 | ￥10,001 ～ ￥30,000 | 1000100-3000000 |
| 30,001〜60,000円 | ￥30,001 ～ ￥60,000 | 3000100-6000000 |
| 60,001〜100,000円 | ￥60,001 ～ ￥100,000 | 6000100-10000000 |

キーワードなしでもHTTP 200で結果は表示されましたが、価格フィルターの表示を確認できず、範囲外の価格も見られました。正常な価格指定検索と断定できないため、9番目は **「おまかせ（ギフト）」** に変更し、キーワード「ギフト」を明示して検索します。「ギフト」検索ではHTTP 200と「￥1,001 ～ ￥5,000」の価格フィルター表示を確認しました。完全なジャンル無指定の検索ではありません。

自動テストは45組のURL生成と共有URLの保存・復元を検証します。Amazonの価格フィルターの実表示は上記のブラウザ確認によるもので、全45組の検索結果を実機確認したものではありません。Amazonの地域・セッション・画面仕様により結果が異なる可能性があります。

### 追加確認

利用するブラウザでも、選んだ価格帯がAmazonの価格フィルターに反映されることを確認してください。Amazon側の仕様が変わった場合は `src/finder.ts` の `buildAmazonUrl` とテストを更新します。

検索結果には広告、価格帯外の商品、金券・ギフト券・サービス券などの対象外商品が含まれる場合があります。価格・在庫・景品への適否は商品ページでご確認ください。

## 主要ファイル

- `src/main.tsx`: 画面、ラジオ選択、URL更新・復元
- `src/style.css`: ダークテーマ、選択状態、フォーカス、狭い画面への対応
- `src/finder.ts`: 予算・ジャンル定数とAmazon URL・共有URLの純粋関数
- `src/finder.test.ts`: 価格帯、ジャンル、URL生成、エンコード、クエリ復元のテスト
- `vite.config.ts`: React・Tailwind・相対アセットパス
- `.github/workflows/deploy.yml`: 型チェック・テスト・ビルド・Pagesデプロイ

デザイン参照画像は提供ファイルに含まれていなかったため、依頼文のレイアウトとダークテーマの仕様を基準にしています。会社情報・個人情報・社内URLは含みません。アンケート導線は実装していません。
